# Forest

An open foundation for trust between strangers: one verified human, one record per market and role, and no platform in the middle. Your records live in folders you own, any app or AI can read them, and money between strangers is held by code.

| Repository | What it is |
|---|---|
| [forest](https://github.com/foundationforest/forest) | The open standard: records, keys, the registry and the escrow. Anyone can build on it. |
| [markets](https://github.com/foundationforest/markets) | The open directory of markets. Anyone can propose one. |
| [services](https://github.com/foundationforest/services) | What the foundation runs on top: an index, an issuer, a relayer and connections. One operator among many; anyone can run their own. |

Nothing is live yet: everything runs on Solana's test network.
